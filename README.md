# ES Manager 使用说明

> 适用版本：v1.4.1
> 最后更新：2026-11-05

ES Manager 是一个 Windows 桌面工具，用来**查看、修改、新增 Elasticsearch 里的数据**，不用再手写 DSL 或开 DevTools。

全部功能都在本地运行，数据直接从你的电脑连到 ES，不经过任何中转服务器。

---

## 一、运行环境

| 项目     | 要求                               |
| -------- | ---------------------------------- |
| 操作系统 | Windows 10 / 11（64 位）           |
| 安装     | **不需要安装**，解压即用           |
| 权限     | 不需要管理员权限                   |
| 运行库   | 不需要装 Node.js、Java、.NET       |
| 网络     | 你的电脑能访问目标 ES 的 9200 端口 |

---

## 二、启动

1. 把收到的 `ESManager-1.4.1-win-x64.zip` **完整解压**到一个目录（例如 `D:\Tools\ESManager`）。

   > 不要在压缩包里直接双击运行，会报错或白屏。

2. 双击目录里的 **`ESManager.exe`**。

3. 如果弹出「Windows 已保护你的电脑」：点「**更多信息**」→「**仍要运行**」。

   这是因为程序没有购买代码签名证书，属正常现象，不影响使用。

4. 首次启动约需 5~15 秒（程序在初始化界面），之后会快很多。

> 建议给 `ESManager.exe` 发送一个桌面快捷方式，以后从桌面打开。

---

## 三、第一次使用：连接 ES

打开后界面是空的，需要先告诉它连哪个 ES。

1. 点右上角「**集群管理**」→「**新增**」。
<img width="1423" height="879" alt="image" src="https://github.com/user-attachments/assets/8d414896-f007-420a-a0eb-3f422b2016d1" />
<img width="929" height="647" alt="image" src="https://github.com/user-attachments/assets/a8227577-983f-40d1-8fb9-356c71814499" />

2. 按下表填写：

| 字段         | 怎么填                                                 |
| ------------ | ------------------------------------------------------ |
| 集群名称     | 随便起，能认出环境即可，如「广州」「测试环境」         |
| ES 地址      | 形如 `http://172.168.27.67:9200`                       |
| 认证方式     | 见下方说明                                             |
| 只读锁       | **默认开启**。只用来看数据就保持开启；要改数据必须关掉 |
| 生产环境     | 如果这是正式环境，勾上。写操作会多一次警告确认         |
| 跳过证书校验 | 只有 ES 用 HTTPS 且是自签名证书时才勾                  |
| 请求超时     | 默认即可。跨网段很慢时可调大                           |

**关于认证方式**，三选一：

- **无认证**：内网 ES 常见，直接能连
- **用户名密码**：填 ES 的账号密码
- **API Key**：填运维给的 API Key

3. 点「**测试连接**」。看到成功提示再保存。

4. 保存后会自动启用，左侧列出该 ES 下的所有索引。

> **端口提示**：填 **9200**（HTTP 接口端口），不要填 9300（那是节点间通信端口，填了连不上）。

## 五、查看数据

### 5.1 查询

1. 左侧点一个索引（如 `t_base_alarm`）。
2. 切到「**数据**」页签。
3. 点「**+ 添加条件**」，选字段、选操作符（等于、包含、大于等）、填值。
4. 需要多个条件时继续添加，并选择条件之间是「且」还是「或」。
5. 点「**查询**」。

**不添加任何条件直接查询 = 查全部数据。**

### 5.2 只用部分字段看

索引字段很多时（`t_base_alarm` 有 154 个），表格横向挤不下。

点结果区右上角「**选择字段**」：

- 搜索框可按名字找字段
- 「全选 / 反选 / 清空」
- 也可以按前缀批量勾选：`所有 I_`（整数）、`所有 S_`（字符串）、`所有 D_`（日期）

勾选后点确定，会**重新查询**——只向 ES 索取这些字段，速度更快、数据量更小（实测减少约 96%）。

**一个字段都不勾 = 查看全部字段**，和以前一样。

点「恢复全部字段」可一键取消。

### 5.3 排序、详情、翻页

- **排序**：点列标题即可，再点一次切换升/降序
- **查看完整内容**：点行尾「详情」，能看到该文档的完整 JSON，可一键复制
- **翻页**：底部选择每页 10 / 20 / 50 / 100 / 200 条
- **总数**：显示在结果区上方，是精确值

### 5.4 想直接写 DSL

切到「**DSL 源码**」模式，自己写查询语句。写错会有语法提示，不会把错误语句发出去。

## 六、修改、新增、删除

### 前提：关闭只读锁

界面右上角显示「只读锁已开启」时，所有修改按钮都是灰的。

点那个状态标签即可切换。**改完数据建议重新打开只读锁**，避免误操作。

### 6.1 修改一条数据

1. 找到目标行，点「**编辑**」。
2. 在表单里改，或切到「JSON 模式」直接改 JSON。
3. 点「保存」。

> 如果你开启了「选择字段」只显示几个字段，编辑时工具会**自动读取该文档的完整内容**，不会因为界面上看不到其他字段就把它们清空。

### 6.2 新增

索引标题旁有两个入口：

- 「**新增文档**」：按字段表单填写
- 「**新增（JSON）**」：直接粘贴完整 JSON

可以指定 `_id`，留空则由 ES 自动生成。

### 6.3 删除

点行尾「详情」→「删除此文档」，需要**手动输入索引名**才会执行。

> **删除不可恢复。** ES 没有回收站。

---

## 七、批量导入

点索引标题旁的「**批量导入**」。

### 7.1 支持三种文件

| 格式      | 长什么样                                 |
| --------- | ---------------------------------------- |
| JSON 数组 | `[ {"字段":"值"}, {"字段":"值"} ]`       |
| NDJSON    | 每行一个 JSON 对象，行与行之间不能有逗号 |
| CSV       | 第一行是表头，之后每行一条数据           |

### 7.2 流程

1. 选择或拖入文件 → 工具自动解析并**预览前几条**
2. CSV 文件会多一步「**字段映射**」：自动按列名匹配 ES 字段，没匹配上的可以手动指定
3. 点「开始导入」，显示进度条
4. 完成后显示成功 / 失败条数，失败明细可一键复制

导入是分批提交的，中途某几条失败不会影响已成功的部分。

---

## 八、导出数据

点「**导出**」：

| 选项     | 说明                           |
| -------- | ------------------------------ |
| 导出范围 | 当前查询结果，或该索引全部数据 |
| 格式     | JSON / CSV                     |
| 字段     | 全部，或自选                   |
| 条数上限 | 防止误导出超大数据             |

完成后可直接打开文件所在文件夹。

> 导出的 CSV 带 UTF-8 BOM，用 Excel 双击打开**中文不会乱码**。

---

## 九、给索引加字段（谨慎）

在「**字段结构**」页签，点右上角「**添加字段**」。

### 必须先知道的三件事

1. **只能加，不能改、不能删。** 字段类型一旦确定就无法修改，加错了只能重建索引（reindex）。
2. **已有的历史数据不会自动补上这个字段**，需要另外批量更新才能回填。
3. **对全索引生效**，不是只影响某一条数据。

### 操作流程

1. 填字段名（工具会实时校验命名是否合法、是否与现有字段冲突）
2. 选类型
3. 确认页会显示将要执行的操作原文，**需要手动输入字段名才能提交**
4. 生产环境会额外弹一次警告

> **建议先在测试索引上试。** 如果不确定类型选哪个，先问维护该索引的人。

## 十、安全设置

| 机制             | 作用                                 |
| ---------------- | ------------------------------------ |
| 只读锁           | 开启时拦截所有写操作。**默认开启**   |
| 生产环境标记     | 标记为生产环境后，写操作会额外弹警告 |
| 删除需输入索引名 | 防止误点删除                         |
| 操作审计日志     | 所有写操作记录在案，便于事后追溯     |

审计日志位置：

```
%APPDATA%\es-manager\logs\audit-年-月-日.log
```

在文件资源管理器地址栏粘贴 `%APPDATA%\es-manager` 即可打开。

---

## 十一、配置保存与备份

你的集群配置保存在本机：

```
%APPDATA%\es-manager\clusters.json
```

- 换版本、重新解压、删除程序目录，**配置都不会丢**
- 想备份或换电脑，复制这个文件即可
- **该文件含 ES 地址与账号密码，不要发给无关人员**

---

## 十二、升级到新版本

1. 关闭正在运行的 ES Manager
2. 解压新版本到**另一个目录**（不要覆盖旧目录，方便回退）
3. 打开新的 `ESManager.exe`

集群配置会自动沿用，不用重新配。确认没问题后再删除旧目录。

## 十三、常见问题

| 现象                                      | 原因与处理                                                   |
| ----------------------------------------- | ------------------------------------------------------------ |
| 双击没反应 / 白屏                         | 大概率是在压缩包里直接双击了。先完整解压再运行               |
| 提示「Windows 已保护你的电脑」            | 未签名程序的正常提示，点「更多信息」→「仍要运行」            |
| 「测试连接」失败                          | 确认端口是 **9200**；确认本机能访问该网段（必要时连 VPN）；HTTPS 且自签名时勾「跳过证书校验」 |
| 明明有数据，查询结果是 0 条               | 检查字段类型与值是否匹配；字符串字段建议用「包含」而不是「等于」；多词全文检索用「包含」。也可切到 DSL 模式逐步排查 |
| 结果上方显示「共 10000 条」但实际更多     | 旧版本的已知问题，v1.4.0 起已修复，升级即可                  |
| 点「编辑」弹窗报 `[object Object]`        | 旧版本的已知问题，v1.4.1 起已修复，升级即可                  |
| 大整数 ID 查到 0 条，或复制出来末尾变成 0 | 旧版本的精度问题，v1.4.0 起已修复，升级即可                  |
| 写入报 `strict_dynamic_mapping_exception` | 该索引不允许写入未定义的字段。先用「添加字段」加上，再写数据 |
| 写入报「只读锁」相关提示                  | 右上角还开着只读锁，点它切到「写操作已允许」                 |
| 导入时提示某几行失败                      | 看失败明细，常见原因是字段类型不匹配（如往数字字段写了文字） |
| 用 Excel 打开导出的 CSV 中文乱码          | 用本工具导出的文件不会乱码；若是别人用其它工具导出的，需另存为 UTF-8 编码 |
| 界面卡顿、滚动不畅                        | 缩小每页条数（如 20 条）；或用「选择字段」只显示必要字段     |

## 十四、使用注意

1. **删除操作不可恢复**，执行前确认选对了索引和文档。
2. **生产环境建议长期开启只读锁**，确需修改时临时关闭，改完立即打开。
3. **不要多人同时改同一批数据**，ES 没有行锁，后提交的会覆盖先提交的。
4. **加字段前先在测试索引验证**，字段类型选错只能重建索引。
5. **不要在查询未完成时狂点查询**，会给 ES 造成不必要的压力。
6. 遇到报错，把**弹窗原文**和**当时执行的操作**记下来，便于排查。

---

## 十五、卸载

1. 关闭程序
2. 删除解压出来的程序目录
3. 如需一并清除配置：删除 `%APPDATA%\es-manager` 整个目录

无需走任何卸载程序，也没写注册表。
